Roles Guide

Coin Seller

What you get: Stock coins, transfer to buyers, earn from sales, level-up benefits.

How to apply:

  1. Open Profile → Apply for Host / Seller
  2. Choose Coin Seller and submit your application
  3. Wait for admin approval (you'll get a notification)
  4. After approval, top-up stock with admin and start transferring coins
Apply as Coin Seller Open Seller Center (if approved)

Host / Creator

What you get: Go live, host party rooms, earn gifts/points, Streamer Center access.

How to apply:

  1. Open Profile → Apply for Host / Seller
  2. Choose Host and describe your streaming experience
  3. Admin reviews within 24–48 hours
  4. Once approved, open Streamer Center and go live from Explore
Apply as Host Open Streamer Center (if approved)

Buying coins (all users)

Profile → Top Up → pay via UPI → submit UTR → admin verifies → coins credited.
