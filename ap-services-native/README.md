# AP Live Service

Fully native React Native / Expo app for AP Live Service.

Gift animation slugs, tokens, and duration match `frontend/gift-animation-config.js`. Do not change the web live frontend unless asked — this app is the native client going forward.

API: `https://api.apservices.in/api`

```powershell
cd ap-services-native
npm install
npx expo start
```

Android (USB debugging):

```powershell
cd ap-services-native
npx expo run:android
```
